# Fundamentos — Métodos Numéricos

Algoritmos básicos y ejemplos de los **métodos numéricos principales**,
sin contexto de parcial. Ideal para estudiar cada tema de forma aislada.

## 📁 Estructura

| Carpeta | Tema | Descripción |
|---------|------|-----------|
| [01-Sistemas-Lineales/](01-Sistemas-Lineales/) | Resolución de Ax=b | Gauss, Jacobi, Gauss-Seidel |
| [02-Ecuaciones-NoLineales/](02-Ecuaciones-NoLineales/) | Búsqueda de raíces | Bisección, Newton, Secante |
| [03-Interpolacion/](03-Interpolacion/) | Interpolación | Lagrange |
| [04-Integracion-Diferenciacion/](04-Integracion-Diferenciacion/) | Cálculo numérico | (reservado) |
| [05-EDO/](05-EDO/) | Ecuaciones diferenciales | Euler, Runge-Kutta |

## 🚀 Uso rápido

```bash
# Sistemas lineales
cd 01-Sistemas-Lineales
octave ejemplo_GaussJacobi_paso_a_paso

# Ecuaciones no lineales
cd 02-Ecuaciones-NoLineales
octave newton_raiz

# etc...
```
