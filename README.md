# Numerical_methods

Este repositorio contiene varios scripts y documentos de métodos numéricos.

## Estructura principal

- `Parcial1/`: contiene la solución del examen con documentos, índices y scripts relacionados a Newton, Bisección y Gauss-Seidel.
- `Parcial2/`: contiene ejercicios adicionales de métodos numéricos y aproximación numérica.
- Otros archivos `.m` en la raíz son scripts independientes de álgebra lineal y métodos numéricos.

## Índice principal

- [Parcial1/INDICE_COMPLETO_EXAMEN.md](Parcial1/INDICE_COMPLETO_EXAMEN.md) - índice completo de la solución del examen.
- [Parcial1/RESPUESTA_PREGUNTA2.md](Parcial1/RESPUESTA_PREGUNTA2.md) - respuesta detallada de la Pregunta 2.
- [Parcial1/TABLA_COMPARATIVA_PREGUNTA2.md](Parcial1/TABLA_COMPARATIVA_PREGUNTA2.md) - tablas comparativas de Newton vs Bisección.
- [Parcial1/RESPUESTA_GaussSeidel_Problema.md](Parcial1/RESPUESTA_GaussSeidel_Problema.md) - solución completa del problema de Gauss-Seidel.
- [Parcial1/GaussSeidel_Problema_Completo.m](Parcial1/GaussSeidel_Problema_Completo.m) - script ejecutable para Gauss-Seidel.
- [Parcial1/Pregunta2_Newton_vs_Biseccion.m](Parcial1/Pregunta2_Newton_vs_Biseccion.m) - script de comparación Newton vs Bisección.
- [Parcial1/newton_raiz_cuadrada.m](Parcial1/newton_raiz_cuadrada.m) - script del método de Newton para raíz cuadrada.

## Notas

Si moviste documentos desde la raíz a `Parcial1`, utiliza el índice de `Parcial1/INDICE_COMPLETO_EXAMEN.md` para encontrar el contenido actualizado.
